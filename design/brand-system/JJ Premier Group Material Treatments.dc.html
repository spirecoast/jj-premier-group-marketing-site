THE FIRST THING A NEW OWNER HOLDS
One process per piece
Never foil plus deboss plus color. Each object gets a single way of carrying the mark, and the material does the rest.
Matte, always
Gloss reads as a franchise print shop. Satin brass, frosted glass, uncoated cotton, matte vinyl.
The rules shorten first
Below 25 mm the flanking rules shorten before anything else. The name stays. If the name cannot survive, the object is too small for the mark.
Brass is a substrate, not a color
Satin brass, etched or foiled, is in the system. Gold ink and gold foil are not.
Renderings
These are drawn, not photographed: each surface is built to show how its process carries the mark. Proof every piece with the vendor before the run, and replace each rendering with a photograph of the real object once it exists.
