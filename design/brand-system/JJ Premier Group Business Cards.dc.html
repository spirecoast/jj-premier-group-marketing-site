Codes are never inverted
Dark modules on a light ground, always. A light-on-dark code decodes on some phone cameras and fails on most dedicated scanners. On print collateral it is banned outright, with no cream variant kept on file.
White panel off Paper
On Linen, Sand, Deep Harbor or Sky 700 the code sits in a white panel with a 10px quiet zone. On Paper it prints direct. The ground is already light enough.
0.72 in floor
108px here is 0.72 in at trim, the smallest a 29-module code stays reliable in hand. Below that, drop the code and print the URL.
