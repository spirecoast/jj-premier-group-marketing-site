07 · Integrations
How IDX and FUB actually wire up
IDX · the listing data
Stellar MLS via an IDX vendor (iHomefinder, IDX Broker, or Showcase) embedded on this domain, or the RESO Web API for a fully custom build. These widgets are the target rendering either way: the vendor default theme is never shipped. Every IDX page carries the MLS attribution line and broker reciprocity notice.
FollowUpBoss · every lead, one inbox
Each widget posts to the FUB Events API with its own tag: valuation, tour, saved-search, contact. Source stays "jjpremiergroup.com," assignment round-robins between Joelyn and Jessica, and the FUB pixel ties browsing history to the contact the moment a form is sent.
Compliance strip
Rendered at the foot of every IDX page: listing courtesy attribution, MLS name and disclaimer, Equal Housing Opportunity mark, and the brokerage identification. It is part of the design system so it never gets "cleaned up" off a page.
LISTING INFORMATION PROVIDED BY STELLAR MLS. IDX INFORMATION IS PROVIDED EXCLUSIVELY FOR CONSUMERS' PERSONAL, NON-COMMERCIAL USE. LISTING COURTESY OF [BROKERAGE]. DEEMED RELIABLE, NOT GUARANTEED. © 2026 STELLAR MLS.

W-19 THE COMPLIANCE STRIP · A COMPONENT, SO IT SHIPS ON EVERY IDX PAGE BY DEFAULT
Interface rules
Navy is furniture
Header, footer, and one full-screen overlay. Everything between them is Paper or white. A navy section in the middle of a page is the tell that the system has been abandoned.
Sky is the focus ring
On screen, Sky 300 earns one job it can't do in print: the active nav underline and the focused field. It never becomes a button on a light ground.
One waterline per screen
The crossed lockup appears once: footer on desktop, contact overlay on mobile. Elsewhere the nav uses the one-line mark, which carries no rule.
No shadows, no radius
Cards are 1px Harbor 100 borders. Hover darkens the border to Deep Harbor over 120ms. Nothing lifts, nothing scales, nothing bounces.
